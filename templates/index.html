使用说明与环境要求

数据库操作通过本机 socket 以管理员身份执行：MySQL / MariaDB 需要 root 的 socket 认证，PostgreSQL 使用 postgres 系统账号。启停按钮走 systemd 服务控制；最小特权模式下需要在 helper 配置 allow_databases = true，并把对应服务单元加入 helper.services。Redis 为键值型数据库，仅提供状态查看与服务控制。备份存放于服务器 /var/backups/lightpanel/databases（0600 权限）；面板创建数据库时保存的账号密码备忘存放在面板状态目录（0600），方便随时查看与复制。

添加站点

      

        

        

        

        
        

        
部署方式选择「自动识别」时，面板会检测已安装的 Nginx 或 Apache 并创建站点配置；选择「Docker 容器」则按镜像启动一个自动重启的容器并映射端口。创建过程在服务器后台执行，可随时打开「任务中心」查看进度和日志。

站点
—

            

          

          

            

            

              

                
                

                  
                  
                

              

              
面板内置 ACME 客户端，通过 HTTP-01 验证域名后自动配置 Nginx/Apache HTTPS 并在到期前 30 天自动续期，无需安装任何外部工具。域名必须解析到本服务器且 80 端口可从公网访问；通配符域名暂不支持。

              

            

          

          

            

            

              

              

                
                
              

              
节点按权重分流，权重留空使用默认值；勾选「备用」的节点只在其他节点全部失效时启用。保存后立即重载 Web 服务，配置错误会自动回滚。

              

            

          

          

            

            

              
              
              

                
                
              

              
设置重定向后，该站点所有请求只做跳转（ACME 证书续期路径自动豁免）。整站重定向优先于强制 HTTPS。

              
              
              

              

            

          

          

            

            

            

              
              
            

            
支持泛解析（*.example.com）与多域名绑定；保存后立即重载 Web 服务，域名已被其他站点绑定时会被拒绝。清空全部域名表示接收所有主机名（_）。
